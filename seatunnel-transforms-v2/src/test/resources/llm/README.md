# Legacy LLM Serialization Fixture

`legacy-boolean-wrapper.base64` contains Java serialization bytes from the
factory-created `LLMMultiCatalogTransform` at commit
`8bea8c681cacccbd99fa642ca0853718980b9234`, before `strict_boolean_output`.
It contains an un-opened `LLMTransform`, with no explicit `serialVersionUID`
and no `strictBooleanOutput` field. The configuration has only dummy values.
No model request is made during generation.

Set `JAVA_HOME` to JDK 8 or 11 and compile the transform module first. From the
repository root, reproduce the implicit UID and compare the serialized bytes:

```shell
./mvnw -T1 -pl seatunnel-transforms-v2 -am -DskipTests verify
bash seatunnel-transforms-v2/src/test/resources/llm/generate-legacy-fixture.sh
```

Expected `serialver` output:

```text
org.apache.seatunnel.transform.nlpmodel.llm.LLMTransform:    private static final long serialVersionUID = 4711686225005641485L;
```

The script compiles the four original LLM classes directly from that commit,
ahead of the current module classes on the classpath. Their supporting classes
were unchanged by this PR; local reactor-built API and Common classes take
precedence over installed snapshots. The generator refuses the current LLM class shape.
An optional output-file argument writes regenerated bytes instead of comparing.
Do not regenerate the fixture using new production classes when changing the
serialization contract: its purpose is to retain an independently produced old
stream, not to make a failing compatibility test pass.

`LLMBooleanOutputTest.readsLegacyFactoryWrapperWithValidationDisabled` reads
these archived bytes with current classes, redirects only the dummy HTTP URL
to a local server, and checks malformed-output coercion, boolean literals,
and row metadata. Ordinary CI needs neither Git history nor a Java compiler
for this test. A changed UID fails deserialization, and enabling strict mode
for the old payload fails the malformed-output assertion. This is an old-plan
serialization regression, not a full cluster-upgrade test.
