# 连接器 V2 特性介绍

## 连接器 V2 与 V1 的区别

自 https://github.com/apache/seatunnel/issues/1608 起，我们添加了连接器 V2 的特性。
连接器 V2 是基于 SeaTunnel Connector API 接口定义的连接器。与连接器 V1 不同，V2 支持以下特性：

*   **多引擎支持** SeaTunnel Connector API 是一个引擎无关的 API。基于此 API 开发的连接器可以在多种引擎中运行。目前支持 Flink 和 Spark，未来我们还将支持其他引擎。
*   **多引擎版本支持** 通过翻译层将连接器与引擎解耦，解决了大多数连接器为了支持新版本的底层引擎而需要修改代码的问题。
*   **批流一体** 连接器 V2 可以执行批处理或流处理。我们无需为批处理和流处理分别开发连接器。
*   **复用 JDBC/日志连接** 连接器 V2 支持 JDBC 资源复用和共享数据库日志解析。
*   **多模态数据集成** 连接器 V2 支持多模态数据集成，包括结构化和非结构化的文本数据、视频、图像、二进制文件等。

## Source 连接器特性

Source 连接器具有一些通用的核心特性，每个 Source 连接器对这些特性的支持程度各不相同。

### 精确一次 (exactly-once)

如果数据源中的每条数据都只会被 Source 向下游发送一次，我们则认为该 Source 连接器支持精确一次。

在 SeaTunnel 中，我们可以在执行检查点（checkpointing）时，将读取的 **分片 (Split)** 及其 **偏移量 (offset)**（当时读取数据在分片中的位置，例如行号、字节大小、偏移位置等）保存为 **状态快照 (StateSnapshot)**。如果任务重启，我们将获取上一次的 **状态快照**，然后定位到上次读取的 **分片** 和 **偏移量**，并继续向下游发送数据。

例如 `File`、`Kafka`。

### 列投影 (column projection)

如果连接器支持仅从数据源中读取指定的列（请注意，如果先读取所有列，然后通过 schema 过滤掉不需要的列，这种方法不属于真正的列投影）。

例如 `JDBCSource` 可以使用 SQL 来定义要读取的列。

`KafkaSource` 会从主题 (topic) 中读取所有内容，然后使用 `schema` 过滤掉不需要的列，这不属于 `列投影`。

### 批处理 (batch)

批处理作业模式。读取的数据是有界的，作业在完成所有数据读取后将停止。

### 流处理 (stream)

流处理作业模式。读取的数据是无界的，作业永不停止。

### 并行度 (parallelism)

支持并行度的 Source 连接器可以配置 `parallelism` 参数，每个并行度都会创建一个任务来读取数据。
在**支持并行度的 Source 连接器**中，数据源将被切分成多个分片 (split)，然后由枚举器 (enumerator) 将分片分配给 SourceReader 进行处理。

### 多模态 (multimodal)

支持多模态数据集成，包括结构化和非结构化的文本数据、视频、图像、二进制文件等。

### 支持用户自定义分片

用户可以配置分片规则。

### 支持多表读取

支持在一个 SeaTunnel 作业中读取多张表。

## Sink 连接器特性

Sink 连接器具有一些通用的核心特性，每个 Sink 连接器对这些特性的支持程度各不相同。

### 精确一次 (exactly-once)

当任何一条数据流入分布式系统时，如果系统在整个处理过程中对任何一条数据的处理都精确地只有一次，并且处理结果正确，则认为该系统满足精确一次一致性。

对于 Sink 连接器，如果任何一条数据只向目标写入一次，则该 Sink 连接器支持精确一次。通常有两种方式实现：

*   目标数据库支持键值去重。例如 `MySQL`、`Kudu`。
*   目标支持 **XA 事务**（这种事务可以跨会话使用。即使创建该事务的程序已经结束，新启动的程序只需知道上一次的事务 ID 即可重新提交或回滚该事务）。然后我们可以使用**两阶段提交**来保证**精确一次**。例如 `File`、`MySQL`。

### cdc (变更数据捕获)

如果一个 Sink 连接器支持基于主键写入行类型 (INSERT/UPDATE_BEFORE/UPDATE_AFTER/DELETE)，我们认为它支持 cdc (变更数据捕获)。

### 支持多表写入

支持在一个 SeaTunnel 作业中写入多张表，用户可以通过[配置占位符](./sink-options-placeholders.md)来动态指定表的标识符。

### 多模态 (multimodal)

支持多模态数据集成，包括结构化和非结构化的文本数据、视频、图像、二进制文件等。
