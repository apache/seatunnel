# SeaTunnel Engine(Zeta) 배포

SeaTunnel Engine(Zeta)는 로컬 모드, 하이브리드 클러스터 모드, 분리형 클러스터 모드의 세 가지 배포 방식을 지원합니다. 각 모드는 사용 시나리오와 장단점이 다르므로 환경과 요구에 맞춰 선택하세요.

- **로컬 모드**: 테스트 용도로만 사용합니다. 작업마다 독립 프로세스를 생성하고 작업이 끝나면 프로세스가 종료됩니다.
- **하이브리드 클러스터 모드**: Master 서비스와 Worker 서비스가 동일 프로세스에 공존합니다. 모든 노드가 작업을 실행하면서 마스터 선출에도 참여하며, 동기화 작업도 동시에 수행합니다. Imap(작업 상태 정보를 저장하는 구조) 데이터는 모든 노드에 분산됩니다.
- **분리형 클러스터 모드(실험적)**: Master와 Worker 서비스를 분리해 각각 단일 프로세스로 운영합니다. Master 노드는 잡 스케줄링, REST API, 작업 제출 등을 담당하며 Imap 데이터를 보관합니다. Worker 노드는 작업 실행만 담당하고 마스터 선출이나 Imap 저장에는 참여하지 않습니다.

> **권장 사항**: 현재는 하이브리드 모드를 주로 사용하지만, 향후에는 분리형 모드가 권장될 예정입니다. 하이브리드 모드에서는 Master 노드가 작업도 직접 실행하므로 대규모 작업 시 안정성이 떨어질 수 있고, Master 장애/스위칭이 전체 작업의 장애 복구를 유발해 클러스터 부하가 증가합니다. 이런 이유로 분리형 모드 사용을 점차 확대할 계획입니다.
