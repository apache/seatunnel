# SeaTunnel Engine

SeaTunnel Engine은 데이터를 동기화하는 시나리오에 최적화된 커뮤니티 개발 엔진으로, SeaTunnel의 기본 엔진입니다. 높은 처리량과 낮은 지연, 강한 일관성을 갖춘 동기화 작업을 지원하며, 더 빠르고 안정적이며 리소스를 절약하면서 사용도 간편합니다.

엔진의 핵심 설계 방향은 다음과 같습니다.

- **더 빠르게**: 실행 계획 최적화로 네트워크 전송을 줄여 직렬화/역직렬화로 인한 성능 손실을 최소화합니다. 동시에 속도 제한 기능을 제공해 적절한 속도로 동기화할 수 있습니다.
- **더 안정적으로**: 파이프라인(Pipeline)을 체크포인트·장애 복구 최소 단위로 사용합니다. 작업 실패가 전체 잡으로 전파되지 않고 해당 파이프라인만 롤백되며, 소스 데이터의 보관 기간 제한이 있는 경우를 위해 데이터 캐시도 지원합니다.
- **공간 절약**: 내부적으로 Dynamic Thread Sharing 기술을 사용합니다. 많은 수의 소량 테이블을 실시간 동기화할 때 스레드를 공유해 불필요한 생성 비용을 줄입니다. JDBC 연결 수도 최소화하고 CDC 시나리오에서는 로그 읽기·파싱 리소스를 재사용합니다.
- **사용 편의성**: 외부 서비스 의존성을 줄여 Zookeeper나 HDFS 같은 빅데이터 컴포넌트 없이도 클러스터 관리·스냅샷 저장·HA를 구현합니다.

앞으로도 오프라인 배치 동기화, 실시간 동기화, CDC에 대한 전체/증분 동기화를 더욱 고도화할 예정입니다.

### 클러스터 관리

- 단일 노드 실행 지원
- 클러스터 실행 지원
- 탈중앙형 자율 클러스터 지원 (마스터 노드를 직접 지정하지 않아도 노드 간 자동 선출 및 장애 시 재선출)
- 동일한 `cluster_name`을 가진 노드끼리 자동으로 클러스터 형성

### 핵심 기능

- 로컬 모드 실행 지원 (잡 완료 후 클러스터 자동 종료)
- 클러스터 모드 실행 지원 (클라이언트로 제출하고 서비스는 잡 종료 후에도 대기)
- 오프라인 배치 동기화 지원
- 실시간 동기화 지원
- 배치·스트림 통합: SeaTunnel V2 커넥터 전부 실행 가능
- 분산 스냅샷 알고리즘 및 2단계 커밋 지원으로 Exactly-Once 보장
- 파이프라인 단위 작업 호출 지원 (제한된 자원에서도 시작 가능)
- 파이프라인 단위 장애 복구 (해당 파이프라인만 롤백)
- 다수의 소규모 데이터셋 실시간 동기화를 위한 동적 스레드 공유
