# 문서 형식 규칙

## 주의 상자(Admonitions)

SeaTunnel 문서는 세 개의 콜론과 유형 라벨을 조합해 강조 블록을 작성합니다. 강조해야 할 내용이 있을 때 사용하면 좋습니다.

사용 시 다음 유형을 참고하세요.

- Tip: 주로 작업 팁이나 노하우를 안내할 때 사용합니다.
- Note: 추가 설명이나 상세 정보를 제공할 때 사용합니다.
- Caution: 경고 또는 주의가 필요한 내용을 전달할 때 사용합니다.

필요하다면 제목을 함께 지정할 수 있습니다. 사용 예시는 아래와 같습니다.

```markdown
:::tip Tip
Some content with tips
:::

:::info Note
Some content with explanations
:::

:::caution Warning
Some content with precautions and warnings
:::
```
