# Connector Changelog

Use this section when you are upgrading SeaTunnel, validating connector compatibility, or checking whether a capability landed in a specific release. It is more useful for version review than for first-time setup.

## Best Use Cases For This Section

- confirm whether a connector feature exists in your target version
- check whether a bug fix was already released
- review upgrade impact before changing production jobs
